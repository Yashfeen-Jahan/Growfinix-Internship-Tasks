# Growfinix Internship - Task 5

## E-commerce Product Filter & Search

This project is a responsive Product Filtering and Search Dashboard developed using React.js and Tailwind CSS as part of my Growfinix Internship.

## 🚀 Features

- 🔍 Search products by name and category
- ⚡ Debounced search
- 🏷️ Category filtering
- 💰 Price filtering
- ⭐ Rating filtering
- 🔗 Multiple filters together
- 🔄 Clear Filters functionality
- 🚫 No Products Found state
- 📦 Dynamic product cards
- 📱 Responsive design

## 🛠️ Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- Vite

## 🧠 React Concepts Used

- Components
- Props
- useState
- useEffect
- Array map()
- Array filter()
- Conditional Rendering
- Custom Hooks
- Debouncing
- Responsive Design

## 🔎 Filtering

Users can filter products using:

- Search
- Category
- Price
- Rating

Multiple filters can also be applied at the same time.

## 📱 Responsive Design

The application is responsive and works on:

- Mobile
- Tablet
- Desktop
