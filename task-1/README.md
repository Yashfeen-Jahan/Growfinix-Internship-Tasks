# Tour Enquiry Dashboard

This project was developed as **Internship Task 1** assigned by **Growfinix**. It is a React-based Tour Enquiry Dashboard that helps manage customer tour enquiries through a clean, responsive, and user-friendly interface.

## Features

- Add new tour enquiries
- View all enquiries
- Edit existing enquiries
- Delete enquiries
- Search enquiries
- Filter enquiries
- Responsive UI
- State management using React Context API

## Tech Stack

- React.js
- JavaScript (ES6+)
- Context API
- Tailwind CSS

## Getting Started

1. Clone the repository
   ```bash
   git clone <https://github.com/Yashfeen-Jahan/Growfinix-Internship-Tasks.git>
   ```

2. Navigate to the project folder
   ```bash
   cd task-1
   ```

3. Install dependencies
   ```bash
   npm install
   ```

4. Start the development server
   ```bash
   npm run dev
   ```
