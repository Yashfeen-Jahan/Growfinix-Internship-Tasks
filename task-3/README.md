# User Account & Session Management Panel

A modern and responsive **User Account & Session Management Panel** built with **React.js**, **Tailwind CSS**, and **React Router**. This application provides a secure login flow, protected routes, user profile management, security settings, preferences management, and logout functionality.

## 🚀 Features

- 🔐 User Login Authentication
- 🛡️ Protected Routes
- 📊 Interactive Dashboard
- 👤 User Profile Management
- 🔒 Security Settings
- ⚙️ Preferences Management
- 🚪 Logout Functionality
- 🎨 Clean UI using Tailwind CSS

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- React Router DOM
- Lucide React
- JavaScript (ES6+)
- Vite

```Bash

```
