# Smart Chat Interface Simulator

A modern AI-inspired chat interface built with React, Tailwind CSS, and Framer Motion. This project simulates a chatbot experience with a clean UI, smooth animations, auto-scrolling, and responsive design.

## 🚀 Features

- Modern chat interface
- Send and receive messages
- Typing indicator animation
- Auto-scroll to latest message
- Smooth message animations
- Clean and user-friendly UI
- AI-ready architecture for future API integration

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- Framer Motion
- JavaScript (ES6+)
- Vite
