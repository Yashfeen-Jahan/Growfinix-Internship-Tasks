# 📝 AI-Powered Text Summarizer

An AI-powered text summarization application built using **React**, **Tailwind CSS**, and **Google Gimini Api**. Users can paste long text, generate concise summaries, and improve reading efficiency.

## 📌 Features

- **Instant AI Summarization:** Get clear and accurate summaries using Google Gemini 2.0 Flash / Hugging Face models.
- **Real-Time Analytics:** Live character, word, and sentence counters that update as you type.
- **Modern & Custom UI:** Responsive design with an earthy, warm color palette built using Tailwind CSS.
- **One-Click Clear:** Effortlessly wipe the input field to summarize fresh text.
- **Copy to Clipboard:** Copy generated summaries with a single click and instant UI feedback.
- **Fully Responsive:** Looks and works great on desktops, tablets, and mobile devices.

## 🛠️ Tech Stack

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/Yashfeen-Jahan/Growfinix-Internship-Tasks.git
```

2. Open the project

```bash
cd task-4
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```


## 🔑 Environment Variables

Create a `.env` file in the project root.

```env
VITE_GEMINI_API_KEY=API_KEY
```
